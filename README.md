# GamesCabinet

Rules-enforced digital board games. Tablet-first. No ads, no microtransactions, no accounts (Phase 1).

**Seed crystal:** [boardgame.io](https://boardgame.io/)

## Phase 1 ladder

1. Tic-tac-toe
2. Connect Four
3. Checkers (English draughts)
4. Dominoes (double-six draw, spinners)

All four local before Railway. Mum invite after Checkers + Dominoes feel calm.
