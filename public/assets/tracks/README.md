# TRACKS card art

Square card faces for the TRACKS board game in this cabinet.

Raster tiles are Bear's GIMP work (tunnel scenes and track parts), composited and exported to WebP at 512 and 1024 px for tablet DPI.

Regenerate from source exports:

```bash
TRACKS_ART_SRC=/path/to/extracted/uploads npx tsx scripts/build-tracks-art.mts
```

Source archives are not committed; only the optimised WebPs ship in this folder.
